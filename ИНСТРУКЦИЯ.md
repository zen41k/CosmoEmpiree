# CosmoEmpire — пошаговая инструкция по сборке

Каталог игровых софтов на **Google Sites** + **Google Sheets** + **Google Apps Script**.

> **Важно прочитать сразу.** Я не могу зайти в ваш Google-аккаунт и создать сайт за вас.
> Всё содержимое уже готово в этой папке — вам остаётся только собрать его
> по шагам ниже. Любой шаг можно сделать на телефоне, но удобнее с компьютера.

---

## Шаг 1. Загрузить файлы в интернет

Google Sites не умеет исполнять ваш HTML напрямую — страницу нужно сначала разместить
по ссылке, а потом встроить её на сайт. Бесплатных способов два.

### Вариант А. GitHub Pages (рекомендуется)

1. Откройте <https://github.com> и войдите в аккаунт.
2. Нажмите **New repository** → имя, например `cosmoempire` → **Create**.
3. На странице репозитория нажмите **uploading an existing file** → перетащите
   **всё содержимое** папки `cosmoempire` (все 4 HTML, папки `css`, `js`, `data`
   и `apps-script`).
4. **Settings** → **Pages** → в «Build and deployment» выберите ветку `main`,
   папку `/ (root)` → **Save**.
5. Подождите 1–2 минуты. Адрес сайта появится здесь же:
   `https://ВАШ_НИК.github.io/cosmoempire/`
6. Откройте эту ссылку — должна открыться главная CosmoEmpire.

> Открывайте `https://...github.io/cosmoempire/catalog.html` для проверки
> каталога — так страницы работают по полной ссылке.

### Вариант Б. Просто скопировать в Google Drive

Подойдёт, если GitHub неудобен. Загрузите папку на Google Диск и откройте файлы
через «Открыть с помощью → Google Docs». **Осторожно:** Google Docs может испортить
код. Для рабочего сайта используйте Вариант А.

## Шаг 2. Создать Google-таблицу

1. Откройте <https://sheets.new> — создастся новая таблица.
2. Переименуйте её: кликните на «Без названия» → введите **CosmoEmpire — каталог**.
3. Пока ничего не заполняйте — таблицу создаст скрипт на следующем шаге.

---

## Шаг 3. Колонки таблицы

Скрипт из шага 4 создаст лист сам. Но если хотите сделать это сразу, впишите
в строку 1 эти заголовки:

| | A | B | C | D | E | F | G | H | I |
|---|---|---|---|---|---|---|---|---|---|
| **1** | Название | Игра | Описание | Цена | Теги | Изображение | Дата добавления | Тип | Просмотры |

> Первые 7 колонок — обязательные (это ваше ТЗ).
> `Тип` нужен для фильтра по типу, `Просмотры` — для сортировки по популярности.
> Если их удалить, сайт продолжит работать: фильтр «Тип» будет пустым,
> а популярность определится по дате добавления.

---

## Шаг 4. Установить Apps Script

1. В таблице меню **Расширения → Apps Script**.
2. В редакторе удалите содержимое файла `Code.gs` и вставьте всё содержимое
   файла `apps-script/Code.gs` из этого комплекта.
3. Откройте **Настройки проекта** (шестерёнка) → поставьте галочку
   **«Показывать манифест appsscript.json в редакторе»**.
4. Скопируйте туда код из `apps-script/appsscript.json`.
5. **Сохранить** (Ctrl+S) → выберите проект, например **CosmoEmpire API**.
6. Выберите функцию `setupCatalog` в списке сверху → нажмите **▶ Выполнить**.
   - Впервые Google спросит разрешения → **Просмотреть разрешения → Разрешить**.
   - Скрипт создаст лист «Товары» и вернёт галочку.
7. В таблице появится меню **CosmoEmpire** — оно подтверждает, что скрипт работает.

---

## Шаг 5. Опубликовать веб-приложение

1. В Apps Script: **Развернуть → Новое развёртывание**.
2. Тип — **Веб-приложение**.
3. **Описание**: `CosmoEmpire API v1`.
4. **Выполнять от имени**: **Я (ваш адрес)**.
5. **Кто имеет доступ**: **Любой** ← обязательно, иначе каталог будет пустым.
6. **Развернуть** → авторизуйтесь.
7. Скопируйте **URL веб-приложения** — он заканчивается на `/exec`:
   ```
   https://script.google.com/macros/s/AKfycbXXXXXXXXXXXXXXXXXXXXXX/exec
   ```

> Проверка: откройте ссылку в браузере и добавьте `?action=ping`.
> Ответ `{"ok":true,...}` означает, что всё работает.

---

## Шаг 6. Подключить адрес к сайту

1. Откройте файл `js/config.js`.
2. Замените пустое значение `API_URL` на вашу ссылку из шага 5:

```js
API_URL: "https://script.google.com/macros/s/AKfycb.../exec",
```

3. Загрузите изменённый `js/config.js` обратно на GitHub.
4. Через минуту откройте `catalog.html` — демо-карточки сменятся данными из таблицы.

### Когда товары появятся

В `data/demo-items.json` лежат 6 демо-карточек. Они показываются, пока таблица пуста,
чтобы каталог не выглядел сломанным. Когда добавите первые настоящие товары —
демо исчезнут автоматически.

Чтобы убрать демо совсем, поставьте в `js/config.js`:

```js
USE_DEMO_WHEN_EMPTY: false,
```

## Шаг 7. Собрать Google Sites

1. Откройте <https://sites.google.com> → **Создать** (пустой сайт, не шаблон).
2. **Название сайта**: `CosmoEmpire`.
3. Перейдите в режим редактирования (иконка карандаша справа).

### Главная страница

1. **Вставка → Изображение** — загрузите логотип или фон (по желанию).
2. Добавьте **заголовок** → текст `CosmoEmpire`.
3. Добавьте **текстовое поле** →
   `Каталог игровых софтов. Ассортимент пополняется.`
4. **Вставка → Встроить** — вставьте главную страницу (см. шаг 8).

### Остальные страницы

**Вставка → Страница** → названия **Каталог**, **О сайте**, **Добавить товар**.

---

## Шаг 8. Встроить страницы (ключевой момент)

Google Sites показывает встроенное окно, поэтому важно указать правильный режим —
иначе страница окажется внутри «внутри».

**Для каждой из 4 страниц** повторите шаги:

1. Откройте нужную страницу сайта.
2. **Вставка → Встроить → Вставить код** → режим **«Сайт Google Sites»**.
3. В строку **URL** вставьте полный адрес из шага 1:

   | Страница сайта | URL для вставки |
   |---|---|
   | Главная | `https://ВАШ_НИК.github.io/cosmoempire/index.html` |
   | Каталог | `https://ВАШ_НИК.github.io/cosmoempire/catalog.html` |
   | О сайте | `https://ВАШ_НИК.github.io/cosmoempire/about.html` |
   | Добавить товар | `https://ВАШ_НИК.github.io/cosmoempire/add-item.html` |

4. Нажмите **Вставить**.

> **Почему именно «Сайт Google Sites», а не «Другой сайт»?**
> Обычная вставка кода прячет страницу в узкую рамку, обрезает её по высоте
> и добавляет лишнюю полосу. Встроенный блок Google Sites растягивает страницу
> на всю ширину контента и не добавляет ничего лишнего.

### Навигация между страницами

Внутри встроенных страниц ссылки работают как обычные (`catalog.html` и т. д.).
Чтобы переходы не выглядели «прыжками внутрь фрейма», добавьте в Google Sites
отдельные **кнопки-ссылки** в меню навигации сайта:

- **Каталог** → `https://ВАШ_НИК.github.io/cosmoempire/catalog.html`
- **О сайте** → `https://ВАШ_НИК.github.io/cosmoempire/about.html`
- **Добавить товар** → `https://ВАШ_НИК.github.io/cosmoempire/add-item.html`

Так посетитель всегда видит сайт Google Sites, а не чужую страницу.

## Шаг 10. Наполнить каталог

Товаров пока нет — добавлять их можно двумя способами.

### Способ 1. Через форму на сайте (для всех)

Откройте «Добавить товар», заполните название, игру, описание, цену, теги
и ссылку на изображение → **Отправить товар**. Строка сразу попадёт в таблицу.

### Способ 2. Прямо в таблице (для вас, быстрее и без модерации)

| Название | Игра | Описание | Цена | Теги | Изображение | Дата добавления | Тип | Просмотры |
|---|---|---|---|---|---|---|---|---|
| External Premium | CS2 | Внешний софт, ESP + aimbot | 1500 | external, esp | https://... | *(пусто)* | Читы | *(пусто)* |

- **Цена** — только число, без знака ₽ и пробелов (иначе будет 0).
- **Теги** — через запятую: `external, esp, aimbot`.
- **Дата добавления** — оставьте пустым, скрипт проставит дату при чтении.
  Если вписать вручную — формат `28.09.2026`.
- **Изображение** — прямая ссылка на картинку или ID файла с Google Диска.
- **Просмотры** — можно не трогать, счётчик растёт сам при открытии карточки.

## Шаг 11. Картинки товаров

1. Загрузите картинку на Google Диск.
2. Откройте **«Доступ» → «Все, у кого есть ссылка»**.
3. Скопируйте **ID файла** из ссылки вида
   `https://drive.google.com/file/d/1АБВГД.../view` — часть после `/d/`.
4. Вставьте ID в колонку «Изображение» или в поле формы — скрипт превратит его
   в рабочую ссылку `https://drive.google.com/uc?export=view&id=...`.

> Не забудьте доступ «Все, у кого есть ссылка», иначе вместо картинки
> посетитель увидит заглушку.

## Если что-то не работает

| Симптом | Причина | Что делать |
|---|---|---|
| Каталог пустой, товары есть | Приложение не опубликовано или нет доступа | Шаг 5, пункт 5 — доступ «Любой» |
| Ошибка 401 / 403 | Приложение требует входа | Опубликуйте заново с доступом «Любой» |
| Форма не отправляется | Не заполнено `API_URL` | Шаг 6 |
| Вместо картинки пустое место | Файл на Диске закрыт | Шаг 11 |
| Цена отображается 0 | В ячейке не число, а текст | Впишите просто `1500` |
| Фильтр «Тип» пуст | Колонка «Тип» не заполнена | Заполните колонку H |
| Дата не показывается | Колонка G пустая | Оставьте пустым — скрипт подставит дату |
| Стили «поехали» | Загружены не все файлы | Проверьте, что папки `css` и `js` целиком |
| Проверить проект | — | `python check.py` в папке проекта |

## Что можно доработать позже

- **Фильтр по типу** — заполните колонку `Тип`; список типов задан в `js/config.js`.
- **Новые игры** — допишите их в массив `GAMES` в `js/config.js`,
  чтобы они появились в выпадающем списке формы.
- **Счётчик просмотров** — уже работает, данные в колонке `Просмотры`.
- **Фото товара в форме** — вместо ссылки можно принимать ссылку на Google Форму,
  которая загружает файл на Диск.

## Итог: что где лежит

```
Google Sites          витрина: 4 страницы + меню
   └── встраивает
GitHub Pages          файлы сайта: HTML, CSS, JS
   └── читает данные из
Apps Script           веб-приложение: /exec?action=items
   └── читает и пишет
Google Sheets         таблица «Товары» — все товары
```

Товар попадает в таблицу → скрипт отдаёт JSON → каталог строит карточки,
фильтры и поиск. Никакой пересборки сайта не нужно.

| Главная | открыть сайт | Заголовок CosmoEmpire, описание, кнопка «Каталог» |
| Пустой каталог | открыть «Каталог» | Пустая сетка + сообщение «Каталог пока пуст» |
| Загрузка данных | `API_URL?action=ping` | `{"ok":true,...}` |
| Поиск | ввести текст в поиск | Список сокращается |
| Фильтры | выбрать игру / тип / цену | Список сокращается, появляются «чипы» |
| Сортировка | выбрать «по популярности» | Порядок меняется |
| «Подробнее» | нажать кнопку на карточке | Открывается окно с описанием и ценой |
| Форма | отправить товар | Строка появляется в таблице |
| Появление в каталоге | обновить «Каталог» | Новая карточка в списке |
| FAQ | открыть «О сайте», раскрыть вопрос | Ответ разворачивается |
